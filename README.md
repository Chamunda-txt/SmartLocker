# SmartLocker

SmartLocker is a Python-based digital locker application designed to store and manage website and file links in one place.

## Features

- Store and manage links
- View saved links
- Open links in a web browser
- Rename and delete saved links

## Technologies

- Python
- MySQL (integration in development)

## Project Status

The Python version is working. MySQL integration is currently in progress.
